FULL-RESOLUTION IMAGE COMPRESSOR

Compress a large image into a smaller JPEG without resizing its pixels. Built for the 1851 Salem map, but works with other browser-readable images. Your image stays on this device: nothing is uploaded.

Default: 23 MiB (about 24.1 MB), below GitHub's 25 MB browser-upload threshold. Use 23 or less to leave room for upload limits.

Choose an image to begin.

Resolution stays intact: a 6,502 × 6,674 image remains 6,502 × 6,674. JPEG is lossy, so fine print and map linework should be checked at 100% zoom. PNG transparency, if present, becomes white. The original file is never modified. A source already under the limit and already JPEG is downloaded unchanged.
